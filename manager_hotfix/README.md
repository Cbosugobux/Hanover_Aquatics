# Global Manual / Legacy Records installer

This folder is only a delivery package for the local Swim Top 10 Manager.

After pulling the Hanover repository into:

`Swim_Top10_Manager\clubs\HNVR\website`

run:

`INSTALL_GLOBAL_MANUAL_ADMIN.bat`

The installer walks up to the manager root and applies the global manual-record backend for HNVR, SCSC, and future clubs.

It does not replace the public Hanover website, CSS, logo, club config, imports, or existing Top 10 JSON data.
